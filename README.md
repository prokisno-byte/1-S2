# ForgeCS — CS2 Team Finder

Платформа для поиска и создания команд Counter-Strike 2 (Premier + Faceit).

**Стиль:** чёрно-белый + красный акцент (в духе G2 Esports)  
**Кнопки:** скруглённые  
**Валидация:** имя — только буквы, возраст и Elo — только цифры

---

## Что уже есть

- Главная страница
- Список команд с фильтрами Premier / Faceit + поиск
- Создание команды
- Регистрация / вход (Email + пароль)
- Вход через Discord (кнопка есть; в демо работает сразу, для реального — настройка Firebase + Discord App)
- Профиль игрока (имя, возраст, Elo, платформа)
- Подача заявки в команду
- Админ-панель (просмотр и принятие/отклонение заявок)
- 10 примеров команд (Premier + Faceit)
- Демо-режим (работает без Firebase через localStorage)
- Секция «Трейды» (заглушка)

---

## Как запустить прямо сейчас (демо)

1. Открой файл `index.html` в браузере  
   или  
2. Залей всю папку `forgecs` на GitHub Pages:
   - Создай репозиторий `username.github.io` или любой другой
   - Загрузи файлы
   - В Settings → Pages выбери ветку `main` / `root`
   - Сайт будет доступен по адресу GitHub Pages

В демо-режиме всё сохраняется в localStorage браузера.

**Админ в демо:** зарегистрируйся с email `admin@forgecs.com` (любой пароль ≥ 6 символов).

---

## Как подключить настоящий Firebase

1. Зайди на [console.firebase.google.com](https://console.firebase.google.com)
2. Создай проект → добавь Web-приложение
3. Скопируй конфиг в файл `js/firebase-config.js`
4. В **Authentication** → Sign-in method → включи **Email/Password**
5. В **Firestore Database** создай базу
6. Правила Firestore (временные, для теста):

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}
```

Позже сделай более строгие правила (только владелец команды может принимать заявки и т.д.).

7. Обнови страницу — демо-режим отключится автоматически.
